Nama aplikasi = Nazo
Fungsi Aplikasi ini = Jadi aplikasi ini adalah cloningan linktree, yang di gunakan untuk menampikan halaman semua social media untuk kebutuhan konten kreator seperti saya

sebelumnya saya sudah memiliki link tree sendiri, ( https://nazothx21.onrender.com )
tapi saya ingin membuat lagi dari awal menggunakan bahasa pemrograman PHP, html, css, dan javascript.
dengan tampilan yang sangat responsif, cepat, dan memiliki tampilan yang elegan, modern, dan juga minimalis.

Untuk desainnya, silahkan anda sesuaikan dengan foto profile Nazo yang akan saya lampirkan nanti..

oke, jadi untuk UI dari aplikasi ini, kurang lebih nanti akan ada halaman utama = menampilkan semua card media sosial saya ( yang nanti akan saya setting di bagian admin ).
lalu ada halaman admin = di halaman admin ini nanti saya bisa menambahkan card, mengedit card, menghapus card, dan juga menambahkan profile picture saya dan juga bio singkat saya.

lalu yang kedua ada fitur tab gallery dan videos = di fitur ini nanti saya bisa menampilkan semua foto dan video saya yang saya unggah ke aplikasi ini, dan bisa di akses oleh siapa saja yang mengunjungi halaman utama saya.

Oh ya, pastikan data yang saya masukkan di halaman admin tersimpan di database sql yang terhubung dengan aplikasi ini. 
untuk storage dan foto foto serta semua yang di butuhkan, nanti masukan saja ke folder foto

Jadi aplikasi ini nantinya akan memiliki 3 halaman utama, yaitu halaman utama, halaman admin, dan halaman gallery dan videos.
